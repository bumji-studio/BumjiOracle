> **แหล่งที่มา:** เพจ *แม่ไม้ดวงจีน 八字 : Destiny Detective* (โพสต์ทฤษฎี “ธาตุทั้ง ๕ กับ อวัยวะสุขภาพร่างกาย”)  
> **หมวดหมู่:** ทฤษฎีการแพทย์จีน / เบญจธาตุและการแพทย์ (五行与健康) / ประธานภายนอก-ประธานภายใน-บริวาร / กลไกความไม่สมดุลก่อโรค / กรณีศึกษาวินิจฉัยสุขภาพ ๔ รูปแบบ

## 1. ปรัชญาเบญจธาตุ: รากฐานแห่งกายวิภาคศาสตร์

ธาตุทั้ง ๕ (ไม้ 火, ไฟ 土, ดิน 金, ทอง 水, น้ำ 木) คือรากฐานของสรรพสิ่งในจักรวาล ร่างกายมนุษย์ถูกหล่อหลอมขึ้นจากสัดส่วนของเบญจธาตุ โดยในแต่ละธาตุมีโครงสร้างการควบคุมอวัยวะแบ่งออกเป็น **๓ ลำดับขั้น** ได้แก่:
1. **ประธานภายนอก (External Primary):** ทวารหรืออวัยวะเปิดภายนอกร่างกายที่สะท้อนพลังธาตุนั้น
2. **ประธานภายใน (Internal Primary):** อวัยวะหลักสำคัญ (ตัน/กลวง) ภายในร่างกาย
3. **บริวาร (Subordinate / Tissues & Energy):** เนื้อเยื่อ โครงสร้าง รยางค์ หรือพลังงานที่ธาตุนั้นหล่อเลี้ยง

## 3. กลไกการเกิดโรคภัยตามหลักปาจื่อ (Pathological Dynamics)

ความเจ็บป่วยไม่ได้เกิดขึ้นอย่างไร้สาเหตุ แต่เกิดจากการ **สูญเสียความสมดุลของธาตุทั้ง ๕** ในดวงเดิม หรือถูกกระตุ้นโดย **วัยจร (大運)** และ **ปีจร (流年)**:
1. **เมื่อธาตุที่ให้โทษ (忌神) มีกำลังมากเกินไป:** เข้าไปโจมตีหรือบดขยี้อวัยวะในสังกัด
2. **เมื่อธาตุที่ให้คุณ (用神) ถูกข่มกลับ (反克):** อวัยวะสำคัญที่ค้ำจุนร่างกายอ่อนแอลงอย่างฉับพลัน
3. **เมื่อธาตุที่ให้โทษข่มธาตุที่ให้คุณโดยตรง:** ก่อเกิดภาวะวิกฤต เช่น มะเร็ง เนื้องอก หรือการผ่าตัดด่วน

## 4. ตัวอย่างการวินิจฉัย ๔ กรณีศึกษาเชิงปฏิบัติ

```
  กรณีที่ ๑ (ดิถี 甲 ทองให้โทษ)       กรณีที่ ๒ (ดิถี 乙 ทองให้โทษ)
       x    甲    x    x                 x    乙    x    x
       x    申    x    x                 x    酉    x    x
    [ปัญหา ศีรษะ/สมอง/หลัง]             [ปัญหา คอ/บ่า/ไหล่]

  กรณีที่ ๓ (ดิถี 己 ไม้ให้โทษ)       กรณีที่ ๔ (ดิถี 丙 ดวงอ่อน ดิน-ทองให้โทษ)
       x    己    甲    x                辛    丙    辛    x
       x    x     寅    x                x    戌    x    x
   [ปัญหา สมอง/ประสาท/ไมเกรน]              [ปัญหา โรคปอด/ทางเดินหายใจ]
```

### กรณีที่ ๑: ดิถีไม้หยาง `甲` นั่งหรือเจอทอง `申` (ทองเป็นโทษ)
* **โครงสร้าง:** `申` (ทองหยาง) ข่มตัดไม้ `甲`
* **การวินิจฉัยโรค:** มีโอกาสเกิดปัญหาเกี่ยวกับ **ศีรษะ, สมอง, กระดูกสันหลัง, หลัง**

### กรณีที่ ๒: ดิถีไม้หยิน `乙` นั่งหรือเจอทอง `酉` (ทองเป็นโทษ)
* **โครงสร้าง:** `酉` (ทองหยิน) ตัดเล็มไม้เลื้อย `乙`
* **การวินิจฉัยโรค:** มีโอกาสเกิดปัญหาเกี่ยวกับ **คอ, บ่า, ไหล่, ไขข้อ, เส้นเอ็น**

### กรณีที่ ๓: ดิถีดินหยิน `己` เจอไม้ `甲` และ `寅` (ไม้เป็นโทษ)
* **โครงสร้าง:** ไม้แข็งแกร่งทะลวงดิน `己` จนดินแตกกระจาย
* **การวินิจฉัยโรค:** มีโอกาสเกิดปัญหาเกี่ยวกับ **โรคทางสมอง, ระบบประสาท, ไมเกรน, เครียดลงกระเพาะ**

### กรณีที่ ๔: ดิถีไฟหยาง `丙` ดวงอ่อน เจอทอง `辛` สองข้างและดิน `戌`
* **โครงสร้าง:** ไฟอ่อนแอถูกดิน `戌` ถ่ายเทพลัง และถูกทอง `辛` รุมรุมล้อม (ดินและทองเป็น 忌神)
* **การวินิจฉัยโรค:** มีโอกาสเกิดปัญหาเกี่ยวกับ **โรคปอด, ระบบทางเดินหายใจ, หลอดลม, ภูมิแพ้**

## 5. ถอดรหัสครูดวง: จา พนม (Tony Jaa) — วิกฤตมะเร็งถุงน้ำดี

```
乾 (ดวงชาย)                วัยจร (49-53)      ปีจร 2569
(甲)    丁    庚    丙         乙             丙
(辰)    亥    寅    辰         (เพียงอิ่ง)       午 (ปี่เกี๊ยบ)
```

1. **การประเมินกำลังดวง:** ดิถีไฟ `丁` เกิดเดือนเสือ `寅` เป็นดวงหยาง (ดวงแข็ง)
2. **กฎดวงแข็ง:** **ไม่ชอบ 印 (อิ่ง - ไม้) และ 比劫 (ปี่เกี๊ยบ - ไฟ)**
   * ไม้ `甲` และ `寅` ในดวงจึงเป็น **忌神 (ธาตุให้โทษ)**
3. **การเข้ามากระทบของวัยจรและปีจร:**
   * **วัยจร `乙`:** คือ **偏印 “เพียงอิ่ง”** (บ่งบอกถึงสุขภาพ ร่างกาย และโรคประจำตัว)
     * ธาตุไม้ (`木`) ในระบบอวัยวะควบคุม **“ถุงน้ำดี”**
   * **ปีจร `丙午`:** คือ **比劫 “ปี่เกี๊ยบ”** (บ่งบอกถึง เจ้ากรรมนายเวร อุปสรรค การสูญเสีย การผ่าตัด)
4. **ผลลัพธ์:** ป่วยเป็น **มะเร็งถุงน้ำดีระยะที่ ๓** ต้องเข้ารับการผ่าตัดและทำเคมีบำบัด
   * ด้วยการรู้เท่าทันและจิตใจที่เข้มแข็ง การรักษาประสบผลสำเร็จ อาการฟื้นตัวดีขึ้น

## 6. สรุปแม่ไม้ประจำทฤษฎี

* **ตรวจเช็คภายนอก $\rightarrow$ ภายใน $\rightarrow$ บริวาร:** ดูจุดที่แสดงอาการแล้วย้อนกลับไปหาธาตุต้นกำเนิด
* **สิบเทพบอกบริบทของโรค:**
  * `印` (อิ่ง) $\rightarrow$ สุขภาพ, ความเสื่อมของร่างกาย, ยา, อาหาร
  * `比劫` (ปี่เกี๊ยบที่เป็นโทษ) $\rightarrow$ เจ้ากรรมนายเวร, การผ่าตัด, การสูญเสียเลือดเนื้อ
* **ความสมดุลคือหัวใจ:** โรคเกิดขึ้นเสมอเมื่อธาตุให้โทษล้นเกิน หรือธาตุให้คุณถูกข่มทำลาย
