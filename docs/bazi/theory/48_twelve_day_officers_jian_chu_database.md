## 1. บทนำและปรัชญาแห่งคัมภีร์เจี้ยนฉูสือเอ้อร์เสิน (建除十二神)

คัมภีร์ **เจี้ยนฉูสือเอ้อร์เสิน (建除十二神)** หรือ **12 Day Officers** เป็นหนึ่งในมรดกทางโหราศาสตร์และดาราศาสตร์จีนที่เก่าแก่ที่สุด มีบันทึกตั้งแต่ยุคราชวงศ์ฉินและฮั่น และได้รับการประมวลเป็นมาตรฐานสูงสุดในคัมภีร์หลวง **เอ็กกี่เปี้ยนฟางซู (《协纪辨方书》)** แห่งราชวงศ์ชิง

ระบบนี้มองว่า พลังงานของฟ้าดินในแต่ละวันไม่ได้เกิดขึ้นอย่างสุ่มสี่สุ่มห้า แต่ไหลเวียนเป็น **"วัฏจักร 12 ขั้นตอน (12 Cyclical Energy Phases)"** โดยเปรียบเสมือนวงจรชีวิตของสรรพสิ่ง:
1. **การก่อกำเนิด (Birth)** ➔ 2. **การชำระล้าง (Purge)** ➔ 3. **การสะสมจนเต็มเปี่ยม (Abundance)** ➔ 4. **ความสมดุล (Equilibrium)** ➔ 5. **การหยั่งรากมั่นคง (Stability)** ➔ 6. **การบังคับใช้ตามกฎ (Execution)** ➔ 7. **การแตกหักปะทะ (Clash)** ➔ 8. **การระมัดระวังมีสติ (Vigilance)** ➔ 9. **การบรรลุผลสำเร็จ (Culmination)** ➔ 10. **การกักเก็บผลผลิต (Harvest)** ➔ 11. **การเปิดทางสู่สิ่งใหม่ (Awakening)** ➔ 12. **การพักฟื้นสะสมพลัง (Dormancy)**

## 2. สูตรคณิตศาสตร์ดาราศาสตร์ในการคำนวณ (Mathematical Formulation)

การหาว่าวันใดเป็นวันอะไรใน 12 Day Officers **ไม่ใช่การสุ่มหรือถาม AI** แต่เป็นสูตรสัมบูรณ์ที่คำนวณจากความสัมพันธ์ระหว่าง **กิ่งดินประจำเดือน (Month Branch)** กับ **กิ่งดินประจำวัน (Day Branch)**:

$$\text{Officer Index} = (\text{Day Branch Index} - \text{Month Branch Index} + 12) \pmod{12}$$

### กฎเกณฑ์ลำดับกิ่งดิน (Branch Index 0 - 11):
- `0`: 子 (จื่อ - ชวด)
- `1`: 丑 (โฉ่ว - ฉลู)
- `2`: 寅 (อิ๋น - ขาล) — *เดือน 1 ทางสุริยคติจีน (สารทลี่ชุน)*
- `3`: 卯 (เหม่า - เถาะ)
- `4`: 辰 (เฉิน - มะโรง)
- `5`: 巳 (ซื่อ - มะเส็ง)
- `6`: 午 (อู่ - มะเมีย)
- `7`: 未 (เว่ย - มะแม)
- `8`: 申 (เซิน - วอก)
- `9`: 酉 (โหย่ว - ระกา)
- `10`: 戌 (ซวี - จอ)
- `11`: 亥 (ฮ่าย - กุน)

### ตัวอย่างการคำนวณ:
- ในเดือน **亥 (กุน - Index 11)** หากพบวัน **子 (ชวด - Index 0)**:
  $$\text{Index} = (0 - 11 + 12) \pmod{12} = 1$$
  ตำแหน่งที่ 1 (เมื่อนับ 0 เป็น 建) คือ **除 (Remove - ฉู)** เสมอ
