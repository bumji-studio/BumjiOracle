# ทฤษฎีที่ 22: 官殺 “กัวสั่วะ” (ดาวขุนนาง & ๗ อสูร) — กฎการเลื่อนตำแหน่ง vs คดีความติดคุก (ดวงอ่อน vs ดวงแข็ง)

> **แหล่งที่มา:** เพจ *แม่ไม้ดวงจีน 八字 : Destiny Detective* (โพสต์ทฤษฎี “กัวสั่วะ”)  
> **หมวดหมู่:** ทฤษฎีสิบเทพ (十神) / 官殺 (กัวสั่วะ) / อุปมาต้นไม้อ่อน vs ต้นไม้ใหญ่ / การเลื่อนยศ vs คดีความ  

---

## 1. นิยามและความหมายของ 官殺 “กัวสั่วะ”

**官 (กัว - 正官 เจี่ยกัว)** และ **殺 (สั่วะ - 七殺 ฉิกสั่วะ)** คือธาตุที่เข้ามาควบคุม/พิฆาตดิถี มีนัยยะสำคัญสองขั้ว:
* **ความหมายเชิงบวก (เมื่อเป็นคุณ):** ชื่อเสียง, เกียรติยศ, ยศศักดิ์, อำนาจบารมี, ตำแหน่งหน้าที่การงาน, กฎหมาย, ระเบียบวินัย, การฝึกฝนอบรม, ความละเอียดรอบคอบ, เครดิตความน่าเชื่อถือ, การรักษาเยียวยา
* **ความหมายเชิงลบ (เมื่อเป็นโทษ):** คดีความ, การถูกฟ้องร้อง, การถูกตรวจสอบ, การจับกุม, จองจำ, ติดคุก, การถูกปลด, ภาระหนี้สินท่วมตัว, การผ่าตัด, การประหารชีวิต

---

## 2. จุดเปลี่ยนของหลักวิชา: “เมื่อใด กัวสั่วะ จึงให้คุณ หรือ ให้โทษ?”

ในตำราดวงจีนดั้งเดิม มักท่องจำกันว่า *“ดวงอ่อนกลัวกัวสั่วะ (เพราะธาตุพิฆาตจะมาทำลายดิถี) และดวงแข็งชอบกัวสั่วะ (เพราะต้องเอามาข่มดิถีที่แข็งเกินไป)”*  
**แต่วิชาแม่ไม้ดวงจีนได้ปฏิวัติมุมมองนี้อย่างลึกซึ้งด้วย “อุปมาแห่งต้นไม้”:**

```
[อุปมาต้นไม้กับกัวสั่วะ]
🌱 ต้นไม้อ่อน (ดวงอ่อน):
   ชอบการดูแล ทะนุถนอม ควบคุมรดน้ำพรวนดิน ตัดแต่งกิ่ง ดัดรูปทรง (ระเบียบวินัย)
   --> คนดวงอ่อน เมื่อเจอกัวสั่วะ จึงฝึกฝนตนเองจน "ได้เลื่อนยศ เลื่อนตำแหน่ง มีชื่อเสียงอำนาจ"

🌳 ต้นไม้ใหญ่โตเต็มวัย (ดวงแข็ง):
   รากหยั่งลึก แผ่กิ่งก้านสาขาใหญ่ ไม่ชอบการมาดัด รังแก หรือกักขังบังคับ
   --> คนดวงแข็ง เมื่อเจอกัวสั่วะ จึงต่อต้าน "เกิดเรื่อง งานเข้า แบกรับภาระ คดีความ ติดคุก ผ่าตัด"
```

## 3. ตารางสรุปกฎการตัดสิน 官殺 (กัวสั่วะ) ตามความแข็งแกร่งของดวง

| สภาพดวงชะตา | ปฏิกิริยาเมื่อพบ 官殺 “กัวสั่วะ” | ผลพยากรณ์รูปธรรม | ข้อยกเว้น |
| :--- | :---: | :--- | :--- |
| **ดวงหยิน (ดวงอ่อน)** | **ให้คุณ (用神)** | **ได้รับการเลื่อนยศ เลื่อนตำแหน่ง** ได้รับการยอมรับ มีเกียรติยศ ชื่อเสียง อำนาจบารมี | เว้นแต่กัวสั่วะนั้นจะไป **ภาคี (合)** แล้วแปรเป็นธาตุที่ให้โทษ |
| **ดวงหยาง (ดวงแข็ง)** | **ให้โทษ (忌神)** | **งานเข้า แบกภาระ เกิดคดีความ** เครดิตเสียหาย ถูกออกหมายจับ จองจำ ติดคุก ถูกผ่าตัด | เว้นแต่กัวสั่วะนั้นจะไป **ภาคี (合)** แล้วแปรเป็นธาตุที่ให้คุณ |

## 4. กรณีศึกษาเปรียบเทียบแห่งปี `甲辰` (พ.ศ. 2567)

ในปี พ.ศ. 2567 ปีจรคือปี **`甲辰`** เป็นข้อพิสูจน์ความจริงเชิงประจักษ์ระหว่าง 2 บุคคลชื่อดังระดับโลกและระดับประเทศ:

```
[กรณีที่ 1: ดวงอ่อนเจอกัวสั่วะ -> รุ่งโรจน์]
โดนัลด์ ทรัมป์ (ปธน. สหรัฐฯ)
- ดิถีดิน 己 เป็น "ดวงอ่อน" (หยินในหยาง)
- ปีจร 甲辰 นำพา 甲 (正官 เจี่ยกัว) เข้ามา
- ดวงอ่อนเจอกัวสั่วะให้คุณ -> ชนะเลือกตั้งเป็นประธานาธิบดีคนที่ 47!

---------------------------------------------

[กรณีที่ 2: ดวงแข็งเจอกัวสั่วะ -> คดีความ]
บิ๊กโจ๊ก พล.ต.อ. สุรเชษฐ์ หักพาล
- ดิถีน้ำ 壬 เป็น "ดวงแข็ง" (หยางในหยิน)
- ปีจร 甲辰 นำพา 辰 (七殺 ฉิกสั่วะ) เข้ามา
- ดวงแข็งเจอกัวสั่วะให้โทษ -> ถูกออกหมายจับและดำเนินคดีความทันที!
```

## 5. ตรรกะสำหรับการเขียนโปรแกรมคำนวณ (`bazi.js`)

```javascript
// ฟังก์ชันประเมินผลกระทบของ 官殺 (Guan Sha)
function evaluateGuanShaImpact(chartStrength, guanShaGod, isTransformedFavorable) {
  const isWeak = chartStrength.includes('WEAK') || chartStrength.includes('YIN');
  const isStrong = chartStrength.includes('STRONG') || chartStrength.includes('YANG');

  // ข้อยกเว้น: หากเกิดการภาคีแปรธาตุ
  if (isTransformedFavorable !== undefined) {
    return isTransformedFavorable ? 'FAVORABLE_PROMOTION' : 'UNFAVORABLE_LAWSUIT';
  }

  // กฎธรรมชาติ: ดวงอ่อนเจอกัวสั่วะ = เลื่อนยศ vs ดวงแข็งเจอกัวสั่วะ = คดีความ
  if (isWeak) {
    return {
      status: 'FAVORABLE',
      outcomeThai: 'เลื่อนยศ เลื่อนตำแหน่ง ได้รับการประกาศเกียรติคุณ มีชื่อเสียงและอำนาจ',
      analogy: 'ต้นไม้อ่อนได้รับการดูแล ฝึกฝน และจัดระเบียบจนเติบโตงดงาม'
    };
  } else if (isStrong) {
    return {
      status: 'UNFAVORABLE',
      outcomeThai: 'เกิดคดีความ ถูกตรวจสอบ เครดิตมีปัญหา แบกรับภาระหนัก เสี่ยงติดคุกหรือผ่าตัด',
      analogy: 'ต้นไม้ใหญ่ไม่ชอบการถูกบังคับกดดัน เมื่อถูกจำกัดจึงเกิดการต้านจนหักโค่น'
    };
  }
}
```
