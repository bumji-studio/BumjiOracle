## 1. แผนภูมิน้ำหนักคะแนนของ 12 ราศีล่าง (Earthly Branches Weight for Wood DM)

สำหรับคนที่มี **ดิถีเป็นธาตุไม้ 甲 (ไม้หยาง) หรือ 乙 (ไม้หยิน)** คะแนนกำลังหนุนจาก 12 ราศีล่าง มีค่าดังนี้:

| ราศีล่าง (Branch) | สัญลักษณ์ / นักษัตร | ธาตุ | น้ำหนักคะแนน (Points) | เงื่อนไขเพิ่มเติม |
| :---: | :---: | :---: | :---: | :--- |
| **亥** | ฮ่าย (หมู) | น้ำ | **1.0 จุด** | ฤดูหนาว หนุนไม้เต็มกำลัง |
| **子** | จื่อ (หนู) | น้ำ | **1.0 จุด** | ฤดูหนาว หนุนไม้เต็มกำลัง |
| **寅** | อิ๋น (เสือ) | ไม้ | **1.0 จุด** | ฤดูใบไม้ผลิ รากไม้แข็งแกร่ง |
| **卯** | เหม่า (กระต่าย) | ไม้ | **1.0 จุด** | ฤดูใบไม้ผลิ รากไม้แข็งแกร่ง |
| **丑** | โฉ่ว (วัว) | ดินเปียก | **0.5 จุด** | **ต้องอยู่เสาเดือนหรือเสาเวลาเท่านั้น** จึงได้คะแนน |
| **辰** | เฉิน (มังกร) | ดินเปียก | **0.5 จุด** | **ต้องอยู่เสาเดือนหรือเสาเวลาเท่านั้น** จึงได้คะแนน |
| **巳, 午, 未, 申, 酉, 戌** | ไฟ / ทอง / ดินแห้ง | ไฟ/ทอง/ดิน | **0 จุด** | ไม่ส่งเสริมกำลังให้ดิถีไม้ |

> 📌 **กฎสำคัญเรื่องดินเปียก (丑 และ 辰):**  
> **"ถ้า 丑 และ 辰 ไม่ได้อยู่เสาเดือนและเสาเวลา จะไม่ให้คะแนน (ถือว่าเป็นดินเฉยๆ ไม่ช่วยหนุนไม้)"**

## 2. กฎการคำนวณและปัดเศษ (Scoring Rules)

1. **ราศีบน (Heavenly Stems):** ตัวที่ส่งเสริมดิถีไม้ (เช่น ธาตุน้ำ 壬, 癸 หรือ ธาตุไม้ 甲, 乙) นับตัวละ **1.0 จุด**
2. **ราศีล่าง (Earthly Branches):** ให้คะแนนตามตารางด้านบน
3. **การปัดเศษ:** หากผลรวมมีเศษ **0.5 ให้ปัดทิ้ง** (เช่น รวมได้ 5.5 จุด $\rightarrow$ นับเป็น **5 จุด**)

---

## 3. ตัวอย่างการคำนวณตามตำรา (Worked Examples)

### ตัวอย่างที่ 1: รวมได้ 4 จุด
```
เสา:    ยาม     วัน     เดือน    ปี
บน:      乙     甲      乙     丙
         1      1       1      -   = 3 จุด (乙, 甲, 乙 เป็นไม้)
ล่าง:     丑     辰      丑     申
        0.5      -     0.5     -   = 1 จุด (丑 อยู่เสายามและเดือน = ได้ตัวละ 0.5)
                                          (辰 อยู่เสาวัน = 0 จุด ไม่ได้อยู่เดือนหรือยาม)
```
* **ผลรวม:** 3 + 1 = **กำลัง 4 จุด**

---

### ตัวอย่างที่ 2: รวมได้ 5.5 ปัดเศษเหลือ 5 จุด
```
เสา:    ยาม     วัน     เดือน    ปี
บน:      甲     甲      甲     乙
         1      1       1      1   = 4 จุด
ล่าง:     辰     申      辰     丑
        0.5      -     0.5     -   = 1.0 จุด (辰 เสายาม=0.5, 辰 เสาเดือน=0.5)
                                              (丑 เสาปี = 0 จุด)
```
* **ผลรวม:** 4 + 1 = **5.5 จุด $\rightarrow$ ปัดเศษ 0.5 ทิ้ง $\rightarrow$ เหลือ 5 จุด**

---

### ตัวอย่างที่ 3: กรณี 自刑 "จือเฮ้ง"
```
เสา:    ยาม     วัน     เดือน    ปี
บน:      甲     甲      乙     丙
         1      1       1      -   = 3 จุด
ล่าง:     辰     午      丑     辰
        0.5      -     0.5     -   = 1.0 จุด (辰 เสายาม=0.5, 丑 เสาเดือน=0.5)
                                              (辰 เสาปี = 0 จุด)
```
* **ผลรวม:** 3 + 1 = 4 หรือ 5 จุด (ตามสภาวะ)
* **เกณฑ์พิเศษ:** 辰 เป็น **自刑 "จือเฮ้ง"** เพราะมีตัวใดตัวหนึ่งอยู่ที่เสาเดือนหรือเสาเวลา

## 4. โครงสร้างข้อมูลสำหรับนำไปเขียนเป็น Code Logic

```javascript
// Rule calculation logic for Wood Day Master (甲 / 乙)
function calculateWoodChartStrength(pillars) {
  let score = 0;
  
  // 1. Check Heavenly Stems (Upper)
  ['hour', 'day', 'month', 'year'].forEach(p => {
    const stem = pillars[p].stem;
    if (['甲', '乙', '壬', '癸'].includes(stem)) {
      score += 1.0;
    }
  });

  // 2. Check Earthly Branches (Lower)
  ['hour', 'day', 'month', 'year'].forEach(p => {
    const branch = pillars[p].branch;
    if (['亥', '子', '寅', '卯'].includes(branch)) {
      score += 1.0;
    } else if (['丑', '辰'].includes(branch)) {
      // 丑 and 辰 only get 0.5 if located at Month or Hour pillar
      if (p === 'month' || p === 'hour') {
        score += 0.5;
      }
    }
  });

  // 3. Round down .5 fractions
  const finalScore = Math.floor(score);
  return finalScore;
}
```
