# ทฤษฎีที่ 34: ปฏิกิริยาภาคีอสมมาตร 六合 (戌 ⮀ 卯) — เมื่อใด 合 “ฮะ” และเมื่อใด 不合 “ไม่ฮะ” (ดินกลบไม้ vs ฮะแปรธาตุไฟ)

> **แหล่งที่มา:** เพจ *แม่ไม้ดวงจีน 八字 : Destiny Detective* (โพสต์ทฤษฎี “戌 ⮀ 卯 : เมื่อใดจึงฮะ และเมื่อใดไม่ฮะ”)  
> **หมวดหมู่:** ทฤษฎีปฏิกิริยาราศีล่าง / 六合 (หลักฮะ อสมมาตร) / ทิศทางของแรง (Vector Dynamics) / ดินกลบไม้ / 合化 (ฮะแปรธาตุไฟ) / 食傷生財

## 1. ปรัชญาหัวใจ: “ทิศทางการอ่านดวง & เวกเตอร์พลังงาน”

วิชาแม่ไม้ดวงจีนยึดหลักฟิสิกส์ธรรมชาติอย่างเคร่งครัด **ปฏิกิริยาจะไม่เป็นสองทางที่เท่ากันเสมอไป (Asymmetric Reaction)**:
* **ดวงเดิมเป็นตัวตั้ง:** ยึด **ดิถี (日主)** เป็นศูนย์กลาง
* **ทิศทางการอ่านในดวงเดิม:** อ่านจาก **ซ้ายไปขวา** (ปี $\rightarrow$ เดือน $\rightarrow$ วัน $\rightarrow$ ยาม)
* **เมื่อมีตัวจรเข้ามากระทบ:** ทั้งวัยจร (大運) และปีจร (流年) ให้อ่านจาก **ขวามาซ้าย** พุ่งเข้าชนดวงเดิม

```
              [ดวงเดิมเป็นตัวตั้ง (อ่าน ซ้าย -> ขวา)]      <=== [จรเข้ามากระทบ (อ่าน ขวา -> ซ้าย)]
                   ปี        เดือน       วัน        ยาม                วัยจร / ปีจร
```

---

## 2. แก่นแท้: เมื่อใด 合 “ฮะ” และเมื่อใด 不合 “ไม่ฮะ”?

ในตำราดั้งเดิมมักท่องจำแบบเหมารวมว่า *“卯 ฮะกับ 戌 กลายเป็นไฟ”*  
แต่วิชาแม่ไม้ดวงจีนชี้ชัดว่า **ขึ้นอยู่กับว่าใครเป็นตัววิ่งเข้าหาใคร!**

```
   (ดวงเดิม)           (ตัวจร)
      卯      <===       戌      =   不合 “ไม่ฮะ” (ดินกลบไม้)
   (ดวงเดิม)           (ตัวจร)
      戌      <===       卯      =   合化 “ฮะห่วย” (ภาคีแปรธาตุเป็นไฟ 火)
```

| ทิศทางของแรง | สถานะปฏิกิริยา | กลไกธรรมชาติเชิงฟิสิกส์ | ผลลัพธ์ธาตุสุทธิ |
| :---: | :---: | :--- | :---: |
| **`戌` $\rightarrow$ `卯`**<br>(戌 จรเข้าหา 卯 ในดวง) | **不合 (ไม่ฮะ)** | **ดินกลบไม้:** ดินภูเขาแห้งแข็ง `戌` โคจรเข้าทับถมต้นไม้/พืช `卯` ทำให้ไม้ถูกฝังกลบ ไม่เกิดการเผาไหม้ | **ธาตุดิน (`土`)** ยังคงสภาพเดิมและทำงานโดยตรง |
| **`卯` $\rightarrow$ `戌`**<br>(卯 จรเข้าหา 戌 ในดวง) | **合化 (ฮะห่วย)** | **ไม้จุดไฟในเตาเผา:** กิ่งไม้แห้ง `卯` โคจรเข้าไปติดไฟในเตาหลอม/คลังไฟ `戌` เกิดการเผาไหม้อย่างสมบูรณ์ | **แปรธาตุเป็นธาตุไฟ (`火`)** อย่างเต็มตัว |

## 3. กรณีศึกษาที่ ๑: `戌` จรเข้าหา `卯` $\rightarrow$ ไม่ฮะ แต่ “ดินกลบไม้”

### โครงสร้างดวงตัวอย่าง (ดิถีไม้หยิน `乙`):
```
                                 ปีจร / วัยจร
X     乙      X      X                X
X     卯      X      X      <--       戌
```
* **สถานะดวงเดิม:** ดิถีไม้ `乙` นั่งบนฐาน `卯` (ไม้หยินแข็งแรง เจริญเติบโต)
* **ตัวจรเข้ามา:** `戌` (สุนัข - ดินแห้ง/คลังไฟ) จรเข้ามากระทบ `卯`
* **การตัดสินปฏิกิริยา:** **不合 “ไม่ฮะ”** ไม่ได้แปรธาตุเป็นไฟ แต่กลายเป็นปรากฏการณ์ **“ดินกลบไม้”**
* **การถอดรหัสสิบเทพ:**
  * `戌` คือ **正財 “เจี่ยไช้” (ทรัพย์สิน เงินทอง การลงทุน ผลประโยชน์)**
  * `卯` คือ **比肩 “ปี่เกี่ยง” (เพื่อน หุ้นส่วน คู่แข่ง ตัวแทนตนเอง)**

```
             [戌 ดินกลบ 卯 ไม้]
                      |
        +-------------+-------------+
        |                           |
  ถ้าธาตุดิน (土) เป็น 用神     ถ้าธาตุดิน (土) เป็น 忌神
   (ดินสำคัญ เสริมดวงชะตา)       (ดินให้โทษ เป็นตัวถ่วง)
        |                           |
  ดินกลบคู่แข่ง/ศัตรู           ดินกลบหุ้นส่วน/เพื่อนฝูง
  ตัดสินใจลงทุนได้กำไร         ขาดคนหนุน ตัดสินใจผิดพลาด
  ได้เงินทองไหลมาเทมา          เสียหาย เสียเงินเสียทอง
```

* **บทวิเคราะห์ตาม 用神 vs 忌神:**
  * **ถ้าธาตุดิน (`土`) เป็น 用神 (ธาตุให้คุณ เสริมดวง):**
    * ดินที่มีกำลังพุ่งเข้ามา **“กลบคู่แข่งและศัตรู”** จนหมดสภาพ ไม่สามารถขึ้นมาแข่งขันได้
    * เจ้าชะตาตัดสินใจเฉียบคม ลงทุนได้ผลกำไรมหาศาล เก็บเกี่ยวทรัพย์สินและเงินทองเต็มเม็ดเต็มหน่วย
  * **ถ้าธาตุดิน (`土`) เป็น 忌神 (ธาตุให้โทษ ตัวถ่วงดวง):**
    * ดินหนาเตอะพุ่งเข้ามา **“ฝังกลบหุ้นส่วน พี่น้อง เพื่อนฝูง หรือทีมงาน”** ทำให้คนรอบข้างหมดพลัง ช่วยเหลือไม่ได้
    * ขาดผู้ช่วยเหลือสนับสนุน เจ้าชะตาตัดสินใจลงทุนผิดพลาดอย่างร้ายแรง เสียหาย ขาดทุนย่อยยับ เสียเงินเสียทอง

## 4. กรณีศึกษาที่ ๒: `卯` จรเข้าหา `戌` $\rightarrow$ ฮะห่วย (合化) “แปรธาตุเป็นไฟ (火)”

### โครงสร้างดวงตัวอย่าง (ดิถีไม้หยาง `甲`):
```
                                 ปีจร / เดือนจร
X     甲      X      X                X
X     戌      X      X      <--       卯
```
* **สถานะดวงเดิม:** ดิถีไม้ `甲` นั่งบนฐานหรือมี `戌` ในดวงเดิม
* **ตัวจรเข้ามา:** `卯` (กระต่าย - ไม้กิ่งแห้ง) จรเข้ามากระทบ `戌`
* **การตัดสินปฏิกิริยา:** **合化 “ฮะห่วย” (六合 ภาคีสมบูรณ์)** ก่อเกิดการเผาไหม้และแปรธาตุกลายเป็น **“ธาตุไฟ (火)”**
* **การถอดรหัสสิบเทพ:**
  * สำหรับดิถีไม้ `甲` ธาตุไฟที่เกิดขึ้นใหม่ คือ **食傷 “เจี้ยะเซีย” (ผลงาน สติปัญญา ไอเดีย ความสามารถ การขยายกิจการ การตลาด)**

```
             [卯 ฮะ 戌 แปรธาตุเป็นไฟ 火 (食傷)]
                             |
               +-------------+-------------+
               |                           |
         ถ้าธาตุไฟ (火) เป็น 用神    ถ้าธาตุไฟ (火) เป็น 忌神
          (ไฟเสริมดวงชะตา)            (ไฟให้โทษ เผาผลาญ)
               |                           |
         食傷 生 財 (เกิดลาภ)         ดำเนินงานผิดพลาด เสียหาย
         ขยายธุรกิจ ขยายสาขา          ไฟไหม้/วอดวาย เสียทรัพย์
         กำไรพุ่งทะลุเป้า             หมดเนื้อหมดตัว
```

* **บทวิเคราะห์ตาม 用神 vs 忌神:**
  * **ถ้าธาตุไฟ (`火`) เป็น 用神 (ธาตุให้คุณ เสริมดวง):**
    * ธาตุไฟที่แปรสภาพขึ้นมาจะเข้าสู่วงจรจักรพรรดิ: **食傷 “เจี้ยะเซีย” $\rightarrow$ 生 “แซ” (ก่อเกิด) $\rightarrow$ 財 “ไช้” (เงินทอง โชคลาภ)**
    * สติปัญญาเฉียบแหลม แผนการตลาดประสบความสำเร็จสูง ขยายธุรกิจ ขยายกิจการ ขยายสาขาได้อย่างรวดเร็ว
    * ผลประกอบการทะลุเป้า มีกำไรเติบโตอย่างก้าวกระโดด
  * **ถ้าธาตุไฟ (`火`) เป็น 忌神 (ธาตุให้โทษ เผาผลาญดวง):**
    * ธาตุไฟกลายเป็นไฟลุกลาม เผาผลาญทรัพยากรและความสงบสุข
    * ดำเนินการผิดพลาด แผนงานล้มเหลว เกิดเหตุไฟไหม้ ข้อผิดพลาดด้านการสื่อสารหรือไอเดียเพ้อฝัน
    * เสียหาย เสียเงินเสียทอง ธุรกิจขาดทุนย่อยยับ

## 5. กฎสรุปสัจธรรมประจำทฤษฎี

1. **六合 ไม่ได้แปลว่าฮะติดเสมอไป:** ทิศทางของแรง (Vector) เป็นตัวชี้ขาด:
   * **`戌` วิ่งหา `卯` $\rightarrow$ ไม่ฮะ (ดินกลบไม้)**
   * **`卯` วิ่งหา `戌` $\rightarrow$ ฮะแปรธาตุเป็นไฟ (合化成火)**
2. **ดินกลบไม้ มี ๒ แง่มุม:**
   * ดินเป็นคุณ = กลบคู่แข่ง กลบศัตรู ชนะการประมูล ได้เงินทอง
   * ดินเป็นโทษ = กลบเพื่อน กลบมิตร ขาดกัลยาณมิตร ตัดสินใจเจ๊ง
3. **ฮะแปรธาตุไฟ มี ๒ แง่มุม:**
   * ไฟเป็นคุณ = 食傷生財 ขยายสาขา ธุรกิจโตระเบิด
   * ไฟเป็นโทษ = ไฟเผาผลาญ ดำเนินการพังพินาศ เสียเงินก้อนโต
