# ทฤษฎีที่ 28: 驛馬 “เอี้ยะแบ้” (申) กับกลุ่มไตรภาคีไฟ (寅午戌) — ๓ รูปแบบการกระตุ้นดิถีน้ำ 壬

> **แหล่งที่มา:** เพจ *แม่ไม้ดวงจีน 八字 : Destiny Detective* (โพสต์ทฤษฎี “เอี้ยะแบ้ 申 กับ 寅午戌”)  
> **หมวดหมู่:** ทฤษฎีดาวจร / 驛馬 (เอี้ยะแบ้) / การเจาะลึกปฏิกิริยากับกลุ่มไตรภาคี / สิบเทพและวงศ์ญาติ  

---

## 1. กลไกการเกิด 驛馬 “เอี้ยะแบ้” ของ `申` (กฎข้ามธาตุดิน)

* **รากฐานธาตุกำเนิด:**  
  กลุ่มไตรภาคี **寅 午 戌** (ธาตุไฟ 火) $\rightarrow$ ก่อเกิด **ธาตุทอง (金)** คือ **`申` (วอก)**
* ⚡ **กฎพิเศษข้ามธาตุดิน:**  
  ตามธรรมชาติ วงจรเบญจธาตุ `ไฟ` ต้องก่อเกิด `ดิน` ก่อน แล้ว `ดิน` จึงก่อเกิด `ทอง`  
  แต่ในปฏิกิริยา **驛馬 “เอี้ยะแบ้” จะกระโดดข้ามธาตุดิน เปลี่ยนไฟเป็นธาตุทอง `申` โดยตรง!**
* **เงื่อนไข:**  
  เมื่อ `申` โคจรเข้ามาพบกับ **ตัวใดตัวหนึ่ง** ในกลุ่ม `寅`, `午`, หรือ `戌` ในดวงเดิม ย่อมกระตุ้นให้เกิดปฏิกิริยาเอี้ยะแบ้ทันที

---

## 2. เจาะลึก 3 รูปแบบการกระทบ (กรณีศึกษาดิถีน้ำ `壬`)

สำหรับดิถีธาตุน้ำหยาง **`壬`** เมื่อตัวม้าอาชา **`申`** (偏印 เพียงอิ่ง = สติปัญญา, ผู้ใหญ่, เจ้านาย, สุขภาพ, ตราตั้ง) จรเข้ามากระทบ:

```
[ตารางเปรียบเทียบการกระทบของ 申 กับ 寅, 午, 戌]
```

### รูปแบบที่ 1: `申` โคจรมากระทบกับ `寅` (食神 เจี้ยะซิ้ง)
* **`寅` ในดวงเดิม:** คือ **食神 “เจี้ยะซิ้ง”** (Action, การกระทำ, ความสามารถ, ฝีมือ, การเดินทาง, ตา, ลูกเขย, หลานชาย)
* **`申` ที่จรเข้ามา:** คือ **偏印 “เพียงอิ่ง”** (ความรู้, ตำแหน่ง, ผู้ใหญ่, เจ้านาย)
* **การทำนาย:**
  * ✅ **เมื่อธาตุทองเป็น 用神 (ให้คุณ):** **ได้รับการสนับสนุนและผลักดันจากผู้ใหญ่ เจ้านาย ได้รับการเลื่อนยศ เลื่อนตำแหน่งใหญ่โต**
  * ❌ **เมื่อธาตุทองเป็น 忌神 (ให้โทษ):** **ถูกผู้ใหญ่กดดัน เข้ามาจู้จี้จุกจิกวุ่นวาย ทำให้หน้าที่การงานติดขัดเสียหาย**

---

### รูปแบบที่ 2: `申` โคจรมากระทบกับ `午` (正財 เจี่ยไช้)
* **`午` ในดวงเดิม:** คือ **正財 “เจี่ยไช้”** (เงินทอง, เงินเดือนประจำ, ทรัพย์สิน, พ่อ, เมียหลวง)
* **การทำนาย:**
  * ✅ **เมื่อธาตุทองเป็น 用神 (ให้คุณ):** **ได้ปรับขึ้นเงินเดือน, มีทรัพย์สินเพิ่มพูน, ฐานะการเงินและครอบครัวมั่นคงขึ้น**
  * ❌ **เมื่อธาตุทองเป็น 忌神 (ให้โทษ):** **เกิดคดีความเรื่องการเงิน, ถูกตรวจสอบทรัพย์สิน, เส้นทางการเงินมีปัญหา**

---

### รูปแบบที่ 3: `申` โคจรมากระทบกับ `戌` (七殺 ฉิกสั่วะ)
* **`戌` ในดวงเดิม:** คือ **七殺 “ฉิกสั่วะ”** (ชื่อเสียง, ยศตำแหน่ง, อำนาจ, กฎหมาย, ระเบียบ, เครดิต, คดีความ, ลูกชาย)
* **การทำนาย:**
  * ✅ **เมื่อธาตุทองเป็น 用神 (ให้คุณ):** **ได้รับการเลื่อนยศ เลื่อนตำแหน่ง หรือลูกชายได้งานใหม่ ได้ปรับตำแหน่งหน้าที่การงานก้าวหน้า**
  * ❌ **เมื่อธาตุทองเป็น 忌神 (ให้โทษ):** **เกิดเรื่องเกิดคดีความ, มีปัญหาเรื่องเครดิต, การค้ำประกันผิดพลาด, หรือเกิดปัญหาหนี้สินจากการกู้ยืม**

## 3. สรุปตรรกะระบบคำนวณสำหรับโปรแกรม (`bazi.js`)

| ตัวในดวงเดิม | ตัวที่จรมา | สิบเทพที่ถูกกระตุ้น | ผลเมื่อทองเป็น 用神 (ให้คุณ) | ผลเมื่อทองเป็น 忌神 (ให้โทษ) |
| :---: | :---: | :--- | :--- | :--- |
| **`寅`** | **`申`** | 食神 (ฝีมือ/ผลงาน) $\leftrightarrow$ 偏印 (เจ้านาย) | **ผู้ใหญ่หนุนหลัง เลื่อนยศตำแหน่ง** | **ผู้ใหญ่กดดัน งานติดขัดเสียหาย** |
| **`午`** | **`申`** | 正財 (เงินเดือน) $\leftrightarrow$ 偏印 (ทรัพย์สิน) | **ขึ้นเงินเดือน มีทรัพย์เพิ่มขึ้น** | **คดีความ ถูกตรวจสอบทรัพย์สิน** |
| **`戌`** | **`申`** | 七殺 (อำนาจ/ลูกชาย) $\leftrightarrow$ 偏印 (ตำแหน่ง) | **เลื่อนยศตำแหน่ง / ลูกชายได้งานใหม่** | **เกิดคดีความ ปัญหาเครดิตค้ำประกัน** |

```javascript
// ตรวจสอบการทำงานของเอี้ยะแบ้ 申 กับกลุ่มไฟ 寅午戌 ใน bazi.js

    case '寅':

        favorableText: 'ได้รับการสนับสนุนจากผู้ใหญ่ เจ้านาย ได้เลื่อนยศ เลื่อนตำแหน่ง',
        unfavorableText: 'ถูกผู้ใหญ่กดดัน เข้ามาวุ่นวาย ทำให้การงานติดขัดเสียหาย'
      };
    case '午':
      return {
        focus: 'WEALTH_OR_FINANCIAL_AUDIT',

        unfavorableText: 'เกิดคดีความ ถูกตรวจสอบทรัพย์สินและเส้นทางการเงิน'
      };
    case '戌':
      return {
        focus: 'AUTHORITY_OR_CREDIT_LAWSUIT',
        favorableText: 'ได้เลื่อนยศ เลื่อนตำแหน่ง หรือบุตรชายได้งานใหม่ปรับตำแหน่งใหม่',
        unfavorableText: 'เกิดเรื่องคดีความ มีปัญหาเรื่องเครดิต การค้ำประกัน หรือหนี้สิน'
      };
    default:
      return null;
  }
}
```
