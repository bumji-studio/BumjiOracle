## 1. ตารางจับคู่ดิถี 10 ธาตุ กับ 財庫 “ไฉ่โข่ว” (คลังสมบัติ)

ในวิชาดวงจีนปาจื่อ คลังสมบัติคือราศีล่างในกลุ่ม **สี่คลัง (辰 戌 丑 未)** ที่ทำหน้าที่เป็นคลังเก็บธาตุโชคลาภ/การเงิน (财星) ของดิถีแต่ละธาตุ:

| ดิถีประจำตัว (Day Master) | ธาตุโชคลาภ (Wealth Element) | 財庫 “ไฉ่โข่ว” (คลังสมบัติ) | ความหมายของคลังตามธรรมชาติ |
| :---: | :---: | :---: | :--- |
| **甲 (ไม้หยาง), 乙 (ไม้หยิน)** | ธาตุดิน (土) | **辰 (เฉิน - มังกร)** | คลังน้ำ/ดินเปียก หนุนรากไม้และกักเก็บทรัพย์ |
| **丙 (ไฟหยาง), 丁 (ไฟหยิน)** | ธาตุทอง (金) | **丑 (โฉ่ว - วัว)** | คลังทอง ดินเปียกหุ้มโลหะมีค่า |
| **戊 (ดินหยาง), 己 (ดินหยิน)** | ธาตุน้ำ (水) | **辰 (เฉิน - มังกร)** | คลังน้ำ แหล่งกักเก็บกระแสเงินสด |
| **庚 (ทองหยาง), 辛 (ทองหยิน)** | ธาตุไม้ (木) | **未 (เว่ย - แพะ)** | คลังไม้ ดินแห้งซ่อนขุมพลังการเติบโต |
| **壬 (น้ำหยาง), 癸 (น้ำหยิน)** | ธาตุไฟ (火) | **戌 (ซวี - หมา)** | คลังไฟ เตาหลอมพลังงานและโชคลาภ |

## 2. กฎเหล็ก: "มีไฉ่โข่ว มิได้แปลว่าจะรวยทุกคน!"

> ⚠️ **"มิใช่ว่าดวงที่มี 財庫 'ไฉ่โข่ว' แล้วจะรวยทุกดวง! ไฉ่โข่วจะให้คุณหรือให้โทษ ขึ้นอยู่กับรูปดวงทั้ง 8 อักษร"**

1. **ไฉ่โข่วเป็นธาตุให้คุณ (喜用神):**
   * เก็บเงินอยู่ มีทรัพย์สินมาก ขยัน หาเงินเก่ง ทรัพย์สินงอกเงย มีมรดกหรือช่องทางรายได้มั่นคง
2. **ไฉ่โข่วเป็นธาตุให้โทษ (忌神):**
   * คลังที่กลายเป็นภาระ ถูกคนรอบตัว/พี่น้องเบียดเบียนเรื่องเงิน เกิดหนี้สิน คลังแตกรั่ว หรือมีทรัพย์สินแต่ใช้ประโยชน์ไม่ได้

## 3. กรณีศึกษาเปรียบเทียบ (Case Studies)

### ตัวอย่างที่ 1: "ไฉ่โข่วที่ให้โทษ (ถูกพี่น้องเบียดเบียนเรื่องเงิน)"

```
เสา:    ยาม     วัน     เดือน    ปี
บน:      戊     己      乙     戊
ล่าง:     辰     丑      卯     申
```
* **ดิถี:** ธาตุดิน **己 (กี้ - ดินหยิน)**
* **กำลังดวง:** **ดวงหยาง (ดวงแข็ง)**
* **ธาตุที่ให้โทษ (忌神):** ธาตุไฟ (火) และ ธาตุดิน (土)
* **การวิเคราะห์คลังสมบัติ:**
  * เสายามมี **辰 (เฉิน)** ซึ่งเป็น "ไฉ่โข่ว" ของดิถีธาตุดิน
  * แต่ตัว 辰 เป็นธาตุดิน (土) ซึ่งเป็น **比劫 "ปี่เกี๊ยบ"** (เพื่อนฝูง/พี่น้อง) และในดวงนี้ **ดินเป็นธาตุให้โทษ!**
  * $\rightarrow$ **辰 จึงเป็น "ไฉ่โข่วที่ให้โทษ"**
* **คำพยากรณ์ชีวิตจริง:**
  * **"ดวงนี้จึงมักถูกพี่น้องหรือคนรอบข้างเบียดเบียนเรื่องเงินทอง"** ให้คนอื่นหยิบยืมเงินแล้วมักไม่ได้คืน หรือต้องรับภาระหนี้สินแทนผู้อื่น

### ตัวอย่างที่ 2: "ไฉ่โข่วที่ให้คุณ (คนเก่ง ขยัน ทรัพย์สินมาก)"

```
เสา:    ยาม     วัน     เดือน    ปี
บน:      辛     乙      癸     丙
ล่าง:     巳     丑      巳     辰
```
* **ดิถี:** ธาตุไม้ **乙 (อิก - ไม้หยิน)**
* **กำลังดวง:** **ดวงหยางในหยิน (ดวงแข็ง)**
* **ธาตุที่ให้คุณ (喜用神):** ธาตุไฟ (火) และ ธาตุดิน (土)
* **การวิเคราะห์คลังสมบัติ:**
  * เสาปีมี **辰 (เฉิน)** ซึ่งเป็น "ไฉ่โข่ว" ของดิถีธาตุไม้
  * ธาตุดิน (土) ในดวงนี้คือ **正財 "เจี่ยไช้"** (ทรัพย์สินเงินทอง/รายได้หลัก)
  * ธาตุไฟ (火) ในดวงนี้คือ **傷官 "เซียกัว"** (สติปัญญา ความสามารถ ความคิดสร้างสรรค์ การลงมือทำ)
  * และทั้งไฟและดินเป็น **ธาตุให้คุณแก่ดวง!**
  * $\rightarrow$ **辰 จึงเป็น "ไฉ่โข่วที่ให้คุณ" อย่างเต็มกำลัง**
* **คำพยากรณ์ชีวิตจริง:**
  * **"ดวงนี้จึงเป็นคนเก่ง มากความสามารถ ขยัน และหาเงินเก่ง มีทรัพย์สินมาก"** ความคิดและสติปัญญา (เซียกัว) สามารถแปรเปลี่ยนเป็นขุมทรัพย์ในคลัง (ไฉ่โข่ว) ได้อย่างงดงาม

## 4. โครงสร้าง Logic สำหรับ BaZi Engine (Code Mapping)

```javascript
// Map Day Master to its Wealth Vault (财库) Branch
const WEALTH_VAULT_MAP = {
  甲: '辰', 乙: '辰', // Wood -> Chen
  丙: '丑', 丁: '丑', // Fire -> Chou
  戊: '辰', 己: '辰', // Earth -> Chen
  庚: '未', 辛: '未', // Metal -> Wei
  壬: '戌', 癸: '戌'  // Water -> Xu
};

function analyzeWealthVault(chart, dayMaster, favorableElements, unfavorableElements) {
  const targetVaultBranch = WEALTH_VAULT_MAP[dayMaster];
  if (!targetVaultBranch) return null;

  // Find occurrences of the vault branch across 4 pillars
  const foundVaults = [];
  ['year', 'month', 'day', 'hour'].forEach(p => {
    if (chart.pillars[p].branch === targetVaultBranch) {
      foundVaults.push({ pillar: p, branch: targetVaultBranch });
    }
  });

  if (foundVaults.length === 0) {
    return {
      hasVault: false,
      vaultBranch: targetVaultBranch,
      desc: 'ไม่มีคลังสมบัติในดวงเดิม (การเก็บออมต้องอาศัยระเบียบวินัยเป็นพิเศษ)'
    };
  }

  // Check if Earth/Vault element is Favorable or Unfavorable
  const isEarthFavorable = favorableElements.includes('earth');
  
  return {
    hasVault: true,
    vaultBranch: targetVaultBranch,
    occurrences: foundVaults,
    isFavorable: isEarthFavorable,
    title: isEarthFavorable 
      ? `💎 คลังสมบัติให้คุณ (财库吉 • ${targetVaultBranch})`
      : `⚠️ คลังสมบัติให้โทษ (财库凶 • ${targetVaultBranch})`,
    reading: isEarthFavorable
      ? 'คลังสมบัติให้คุณ: เป็นคนขยัน ฉลาดหาเงิน ทรัพย์สินงอกเงย เก็บเงินอยู่ มีโอกาสสะสมความมั่งคั่งได้มาก'
      : 'คลังสมบัติให้โทษ: ระวังถูกคนใกล้ชิด เพื่อนฝูง หรือพี่น้องเบียดเบียนเรื่องเงินทอง ไม่ควรให้กู้ยืมหรือค้ำประกัน'
  };
}
```
