## 1. นิยามของ 六亲 “หลักชิง” (วงศ์ญาติ)

六亲 “หลักชิง” คือ **ปฏิกิริยาของธาตุทั้ง ๕ ที่สะท้อนผ่าน 十神 “จับซิ้ง” (สิบเทพ)** โดยจำแนกความสัมพันธ์เป็นบุคคลต่างๆ ในครอบครัวและคนรอบข้าง:
* บ่งบอกถึง **เรื่องราว เหตุการณ์ โชคลาภ หรือเคราะห์กรรมที่เกิดขึ้นกับบุคคลต่างๆ ในวงศ์ญาติ**
* **ประโยชน์พิเศษสูงสุด:** ใช้ในการ **"วิเคราะห์คำนวณหาเวลาเกิด" (Birth Time Rectification)** สำหรับผู้ที่ไม่รู้เวลาเกิดที่แน่นอนของตนเอง โดยสอบทานย้อนกลับจากประวัติครอบครัว ความสัมพันธ์ และเหตุการณ์สำคัญในชีวิต

## 2. ตารางมาตรฐาน: สิบเทพ (十神) vs วงศ์ญาติ (六亲) แยกเพศชาย-หญิง

ความสัมพันธ์ของสิบเทพจะมีความหมายแทนบุคคล **แตกต่างกันตามเพศของเจ้าชะตา (ดิถีชาย 乾造 vs ดิถีหญิง 坤造)** ดังนี้:

| 十神 “จับซิ้ง” (สิบเทพ) | ความหมายธาตุสากล | 六亲 วงศ์ญาติของดิถีชาย (乾) | 六亲 วงศ์ญาติของดิถีหญิง (坤) |
| :--- | :--- | :--- | :--- |
| **比肩 “ปีเกย” (Friend)** | ธาตุเดียวกับดิถี (ขั้วเดียวกัน) | **พี่ชาย, น้องชาย** | **พี่สาว, น้องสาว** |
| **劫財 “เกี๊ยบไช้” (Rob Wealth)** | ธาตุเดียวกับดิถี (ต่างขั้ว) | **พี่สาว, น้องสาว, ลูกสะใภ้** | **พี่ชาย, น้องชาย** |
| **食神 “เจี้ยะซิ้ง” (Eating God)** | ธาตุที่ดิถีถ่ายเท (ขั้วเดียวกัน) | **ตา, ลูกเขย, หลานชาย** (จากลูกชาย) | **ลูกสาว, ย่า** |
| **傷官 “เซียกัว” (Hurting Officer)** | ธาตุที่ดิถีถ่ายเท (ต่างขั้ว) | **ย่า, หลานสาว** (จากลูกชาย) | **ลูกชาย, ตา** |
| **偏財 “เพียงไช้” (Indirect Wealth)** | ธาตุที่ดิถีพิฆาต (ขั้วเดียวกัน) | **พ่อ, เมียน้อย** | **พ่อเลี้ยง, หลานสาว** (จากลูกสาว) |
| **正財 “เจี่ยไช้” (Direct Wealth)** | ธาตุที่ดิถีพิฆาต (ต่างขั้ว) | **พ่อเลี้ยง, เมียหลวง (ภรรยา)** | **พ่อ, หลานชาย** (จากลูกสาว) |
| **七殺 “ฉิกสั่วะ” (Seven Killings)** | ธาตุที่พิฆาตดิถี (ขั้วเดียวกัน) | **ลูกชาย** | **แฟน/คนรัก, ลูกสะใภ้, ยาย** |
| **正官 “เจี่ยกัว” (Direct Officer)** | ธาตุที่พิฆาตดิถี (ต่างขั้ว) | **ลูกสาว, ยาย** | **สามี** |
| **偏印 “เพียงอิ่ง” (Indirect Resource)** | ธาตุที่ก่อเกิดดิถี (ขั้วเดียวกัน) | **แม่เลี้ยง, หลานชาย** (จากลูกสาว), **ปู่** | **แม่, หลานสาว** (จากลูกชาย) |
| **正印 “เจี่ยอิ่ง” (Direct Resource)** | ธาตุที่ก่อเกิดดิถี (ต่างขั้ว) | **แม่, หลานสาว** (จากลูกสาว) | **แม่เลี้ยง, หลานชาย** (จากลูกชาย), **ลูกเขย, ปู่** |

## 3. การอ่านวงศ์ญาติผ่าน 暗藏 “อ่ำชั้ง” (ราศีแฝงในราศีล่าง)

การดูวงศ์ญาติมิได้ดูเฉพาะก้านฟ้า (ราศีบน) เท่านั้น แต่ต้องพิจารณา **"ราศีแฝง (暗藏)"** ในนักษัตรราศีล่างด้วย:

### ตัวอย่างที่ 1: ดวงชายดิถีดิน 戊 (โบ่ว)
```
เสา:    ยาม     วัน     เดือน    ปี
บน:      x      戊      x      己
ล่าง:     x      寅      x      x
```
* **ราศีบน:** `己` (ดินหยิน) คือ **劫財 "เกี๊ยบไช้"** $\rightarrow$ หมายถึง **พี่สาวหรือน้องสาว**
* **ราศีล่าง 寅 (เสือ):** มีราศีแฝง 3 ตัวคือ 甲, 丙, 戊
  * แฝง `甲` (ไม้หยาง) คือ **七殺 "ฉิกสั่วะ"** $\rightarrow$ หมายถึง **ลูกชาย**
  * แฝง `戊` (ดินหยาง) คือ **比肩 "ปีเกย"** $\rightarrow$ หมายถึง **พี่ชายหรือน้องชาย**

### ตัวอย่างที่ 2: ดวงหญิงดิถีไม้ 乙 (อิก)
```
เสา:    ยาม     วัน     เดือน    ปี
บน:      x      乙      x      甲
ล่าง:     x      x       x      午
```
* **ราศีบน:** `甲` (ไม้หยาง) คือ **劫財 "เกี๊ยบไช้"** $\rightarrow$ หมายถึง **พี่ชายหรือน้องชาย**
* **ราศีล่าง 午 (ม้า):** มีราศีแฝง `丁` (ไฟหยิน) และ `己` (ดินหยิน)
  * แฝง `丁` คือ **食神 "เจี้ยซิ้ง"** $\rightarrow$ หมายถึง **ลูกสาว**

## 4. ปฏิกิริยาของวัยจรและปีจรต่อวงศ์ญาติ (Life Events Impact)

เมื่อวัยจรหรือปีจรโคจรเข้ามา จะกระตุ้นดาววงศ์ญาติ (六亲) ให้เกิดเหตุการณ์สำคัญในชีวิต:

### กรณีศึกษา: ปีจร 丙午 (กัวสัวะ) เข้ามากระทบดวงดิถีทอง 庚 (แก)
```
ดิถี:    วัน 庚辰
ปีจร:   พ.ศ. 2569 (ปี 丙午 - ธาตุไฟ 官殺 "กัวสั่วะ")
```
* **ถ้าเจ้าชะตาเป็น ผู้ชาย (乾造):**
  * `七殺 (ฉิกสั่วะ)` หมายถึง **ลูกชาย** หรือ **อำนาจหน้าที่**
  * $\rightarrow$ ปี 丙午 มีโอกาส **ได้ลูกชาย** หรือ **ได้รับการเลื่อนยศ เลื่อนตำแหน่งหน้าที่การงาน**
* **ถ้าเจ้าชะตาเป็น ผู้หญิง (坤造):**
  * `七殺 (ฉิกสั่วะ)` หมายถึง **เนื้อคู่ คนรัก แฟน** หรือ **อำนาจหน้าที่**
  * $\rightarrow$ ปี 丙午 มีโอกาส **ได้พบเนื้อคู่ ได้คนรัก แต่งงาน** หรือ **ได้รับการเลื่อนตำแหน่งการงาน**

## 5. เทคนิคการสอบทานหาเวลาเกิด (Birth Time Rectification)

หากผู้ใช้ไม่ทราบเวลาเกิด ให้สอบถามและใช้เกณฑ์ตรวจสอบดังนี้:
1. **เรื่องบุตร (Children):**
   * ชาย: มีลูกชาย (ฉิกสั่วะ) หรือลูกสาว (เจี่ยกัว) เป็นคนแรก ในปีใด
   * หญิง: มีลูกชาย (เซียกัว) หรือลูกสาว (เจี้ยซิ้ง) ในปีใด
2. **ความสัมพันธ์กับพ่อแม่ (Parents):**
   * ความผูกพันกับพ่อ (เพียงไช้/เจี่ยไช้) หรือแม่ (เจี่ยอิ่ง/เพียงอิ่ง)
3. **ปีที่แต่งงาน / หย่าร้าง (Marriage & Divorce):**
   * ดาวคู่ครอง (ชาย=เจี่ยไช้, หญิง=เจี่ยกัว/ฉิกสั่วะ) ถูกกระตุ้นหรือถูกกระทบ (ฮะ/ชง) ในปีใด
4. **นำเหตุการณ์เหล่านี้ไปทดสอบพล็อตเวลาเกิด 12 ชั่วยาม (จื่อ-กุน)** เพื่อหาชั่วยามที่เหตุการณ์และวงศ์ญาติตรงกับความเป็นจริงที่สุด
