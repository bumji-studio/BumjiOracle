## 1. ปรัชญาการวิเคราะห์สุขภาพและโรคภัย

* **หลักการพื้นฐาน:** ความเจ็บป่วยในดวงจีน เกิดจากความไม่สมดุลของเบญจธาตุ (มากเกินไป หรือ พร่องเกินไป)
* **กฎการกระทบของเคราะห์สุขภาพ:**
  * **ดวงแข็งไม่เอา 印 “อิ่ง” (ตัวกำเนิด) และ 比劫 “ปี่เกี๊ยบ” (ตัวธาตุเหมือน):** หากวัยจรหรือปีจรพาธาตุเหล่านี้เข้ามา จะกลายเป็น **忌神 (ธาตุให้โทษ)** ที่เข้าไปกระตุ้นอวัยวะประจำธาตุนั้นให้เกิดความวิปริต แตกหัก อักเสบ หรือกลายเป็นเนื้อร้าย (มะเร็ง)
  * **印 “อิ่ง”** บ่งบอกถึง **สุขภาพ ร่างกาย และโรคประจำตัว**
  * **比劫 “ปี่เกี๊ยบ” (ที่เป็นตัวให้โทษ)** บ่งบอกถึง **เจ้ากรรมนายเวร อุปสรรคขัดขวาง การผ่าตัด และภัยคุกคาม**

## 2. ตารางแม่บทธาตุทั้ง ๕ กับ อวัยวะและโรคภัยในร่างกาย

| ธาตุ | ราศีบน / ราศีล่าง | อวัยวะและระบบในร่างกายที่เกี่ยวข้อง | กลุ่มโรคและอาการเสี่ยง |
| :---: | :---: | :--- | :--- |
| **ไม้ (木)** | **รวมทั่วไป** | **ตับ, ถุงน้ำดี**, ไขข้อ, ระบบประสาทสมอง, เส้นใยเส้นเอ็น, ศีรษะ, กล่องเสียง, คอ, บ่า, ไหล่, กระดูกสันหลัง, แขนขา, นิ้วมือ | ตับอักเสบ, นิ่วในถุงน้ำดี, มะเร็งถุงน้ำดี, ปวดข้อ, เอ็นยึด, พังผืด, ไมเกรน, ปัญหาระบบประสาท |
| | **`甲` / `寅` (หยาง)** | **ถุงน้ำดี**, ศีรษะ, สมอง, กระดูกสันหลัง | ถุงน้ำดีอักเสบ/มะเร็ง, โรคสมอง, กระดูกสันหลังคด/ทับเส้น |
| | **`乙` / `卯` (หยิน)** | **ตับ**, ไขข้อ, คอ, บ่า, ไหล่, เส้นใยเส้นเอ็น, แขนขา, นิ้วมือ | ไขมันพอกตับ, ตับแข็ง, นิ้วล็อค, ออฟฟิศซินโดรม, ข้ออักเสบ |
| **ไฟ (火)** | **รวมทั่วไป** | **หัวใจ**, เยื่อหุ้มหัวใจ, “ซานเจียว” (สามส่วน), ลำไส้เล็ก, ตา, ลิ้น, หลอดเลือด, ระบบเลือด, ความดัน | โรคหัวใจ, ความดันโลหิตสูง/ต่ำ, เลือดจาง, โรคตา, สายตาเสื่อม, หลอดเลือดหัวใจตีบ |
| | **`丙` / `巳` (หยาง)** | **เยื่อหุ้มหัวใจ**, ตา, ลำไส้เล็ก, ระบบเลือด, ความดัน | ความดันโลหิต, ปัญหาลำไส้เล็ก, เลือดข้น, สายตา |
| | **`丁` / `午` (หยิน)** | **หัวใจ**, ลิ้น, ระบบหมุนเวียนโลหิตส่วนกลาง | กล้ามเนื้อหัวใจขาดเลือด, หัวใจเต้นผิดจังหวะ, ลิ้นหัวใจรั่ว |
| **ดิน (土)** | **รวมทั่วไป** | **ม้าม, กระเพาะอาหาร**, ผิวหนัง, อก, ท้อง, กล้ามเนื้อ, ปาก, เอว, ริดสีดวงทวาร, **มะเร็ง**, โรคอ้วน, เบาหวาน | เนื้องอก, มะเร็ง, กรดไหลย้อน, กระเพาะอาหาร, ภูมิแพ้ผิวหนัง, อ้วน, เบาหวาน |
| | **`戊` / `辰` / `未` (หยาง/แห้ง/ร้อน)** | **ท้อง, อก, หลัง**, ผิวหนัง, กล้ามเนื้อ | ปวดท้อง, แน่นหน้าอก, ปวดหลัง, ผื่นคัน, กล้ามเนื้ออักเสบ |
| | **`己` / `丑` / `戌` (หยิน/แฉะ/ชื้น)** | **ม้าม, กระเพาะอาหาร** | ม้ามพร่อง, ย่อยยาก, ท้องอืด, กระเพาะเป็นแผล, ริดสีดวง |
| **ทอง (金)** | **รวมทั่วไป** | **ปอด, ลำไส้ใหญ่**, หลอดลม, ระบบทางเดินหายใจ, จมูก, ฟัน, กระดูก, สะโพก, สะดือ, ภูมิแพ้ | ภูมิแพ้อากาศ, หอบหืด, ไซนัส, ปอดอักเสบ, ลำไส้ใหญ่อักเสบ, กระดูกเปราะ |
| | **`庚` / `申` (หยาง)** | **ลำไส้ใหญ่**, สะดือ, หลอดลม, ระบบทางเดินหายใจ | มะเร็งลำไส้ใหญ่, หลอดลมอักเสบ, หายใจขัด |
| | **`辛` / `酉` (หยิน)** | **ปอด**, สะโพก, ฟัน, ผิวสัมผัส | ภูมิแพ้, ปอดติดเชื้อ, ฟันผุ, กระดูกสะโพกเสื่อม |
| **น้ำ (水)** | **รวมทั่วไป** | **ไต, กระเพาะปัสสาวะ, มดลูก**, อวัยวะสืบพันธุ์, ระบบภูมิคุ้มกัน, โรคแพ้ภูมิตัวเอง (SLE) | โรคไต, กระเพาะปัสสาวะอักเสบ, มีบุตรยาก, ซีสต์ในมดลูก, รูมาตอยด์, SLE |
| | **`壬` / `亥` (หยาง)** | **กระเพาะปัสสาวะ**, ทางเดินปัสสาวะ | กระเพาะปัสสาวะอักเสบ, ทางเดินปัสสาวะติดเชื้อ |
| | **`癸` / `子` (หยิน)** | **ไต**, หู, ระบบน้ำเหลือง, อวัยวะสืบพันธุ์ | ไตวาย, น้ำในหูไม่เท่ากัน, ประจำเดือนผิดปกติ |
