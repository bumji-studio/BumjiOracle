# ทฤษฎีที่ 31: ดิถีไม้หยิน 乙 (ธรรมชาติไม้เลื้อยฉ่ำน้ำ) — ราศีแฝง 癸 ในตัว และกฎภาคีอสมมาตร (乙-庚 vs 庚-乙)

> **แหล่งที่มา:** เพจ *แม่ไม้ดวงจีน 八字 : Destiny Detective* (โพสต์ทฤษฎี “ดิถีธาตุไม้ 乙 พลังหยิน”)  
> **หมวดหมู่:** ทฤษฎี ๑๐ ดิถี (十干) / ดิถีไม้หยิน (乙) / พฤกษศาสตร์ธรรมชาติ / กฎการภาคีแปรธาตุอสมมาตร (Asymmetric Wu He)  

---

## 1. ธรรมชาติฟิสิกส์แห่งดิถีไม้หยิน `乙` (Yin Wood)

* **คุณลักษณะทางพฤกษศาสตร์:**
  * อ่อนช้อย ยืดหยุ่น เกาะเกี่ยว แพร่ขยาย ปกคลุม แตกหน่อขยายพันธุ์
  * สัจธรรมของพืชประเภทนี้: *“กินใบตัดดอก กินลูกตัดใบ กินหน่อถอนต้น ยิ่งตัดยิ่งแตก แตกกิ่ง แตกราก แตกยอด แตกใบ แตกแขนง”*
* **การอุปมาตามธรรมชาติ:**
  * ไม้เลื้อย, ไม้เถาวัลย์, ไม้ดอก, ไม้ประดับ, ไม้ผล, ไม้ล้มลุก, ไม้ไม่มีแก่น (เช่น ต้นกล้วย)
  * **พืชฉ่ำน้ำ:** พืชผักที่มีน้ำอยู่ภายใน เมื่อบีบขยี้จะมีน้ำซึมออกมา เช่น ผักบุ้ง, ตำลึง, ขึ้นฉ่าย, ถั่วงอก, มะเขือเทศ, มะนาว
  * **ผลไม้ฉ่ำน้ำ:** แอปเปิ้ล, สาลี่, ส้ม, แตงโม, สับปะรด

---

## 2. ความลับสำคัญ: “ไม้ 乙 มีน้ำ 癸 ปนอยู่ในเนื้อเสมอ”

> [!IMPORTANT]
> **“พืชไม้หยิน 乙 มีน้ำ 癸 ซึมซับอยู่ภายในเนื้อไม้เสมอ หมายถึง มี 偏印 ‘เพียงอิ่ง’ ฝังอยู่ในตัวโดยกำเนิด”**

### บุคลิกภาพและอุปนิสัยของคนดิถี 乙:
* **จุดเด่น:**
  * มีความเมตตา จิตใจอ่อนโยน ถ่อมตน อดทนสูง
  * สติปัญญาดี ฉลาด มีหัวศิลปะ ความคิดอ่านลึกซึ้ง ช่างคิด ช่างจินตนาการ เป็น **“จอมวางแผน / จอมโปรเจกต์”**
  * ใฝ่รู้ ชอบเรียนรู้ศาสตร์ต่างๆ แสวงหานวัตกรรม พัฒนาและปรับปรุงสิ่งใหม่ๆ ตลอดเวลา
  * หน้าตาและอุปนิสัยมักจะคล้ายคุณแม่ (เพราะมีดาวแม่ 偏印 อยู่ในเนื้อธาตุ)
  * รูปร่างหน้าตาสวยงาม ทักษะการแสดงเก่ง ปรับตัวและประยุกต์เก่ง เข้ากับผู้คนง่าย มือไว ไหวพริบเร็ว รู้จักแสวงหาผลประโยชน์
* **จุดด้อยที่ต้องระวัง:**
  * รุ่มร่าม, ชอบฉวยโอกาสแต๊ะอั๋ง, มือไม้ไวแบบ **“มือปลาหมึก”**
  * ชอบเกาะเกี่ยวเฉพาะคนที่มีผลประโยชน์ แล้วค่อยๆ เลื้อยเข้าไปครอบคลุมควบคุมเขา (เปรียบดั่งวัชพืช)

## 3. กฎเหล็กการภาคีแปรธาตุอสมมาตร (Asymmetric Wu He: 乙 ⮀ 庚)

ในวิชาแม่ไม้ดวงจีน การจับคู่ภาคี 五合 “โหงวฮะ” ราศีบนระหว่าง `乙` กับ `庚` **มีทิศทางของพลังงานที่ไม่เท่ากัน**:

```
[ทิศทาง A: 乙 เข้าหา 庚]                [ทิศทาง B: 庚 เข้าหา 乙]
     乙  -->  庚                             庚  -->  乙
  ไม้เลื้อยยอมเกาะเกี่ยวกับทอง             ขวานทองฟันเข้าใส่ไม้เลื้อย
  "合 (ฮะ) และแปรธาตุเป็นทอง 庚"             "不合 (ไม่ฮะ) เป็นทองตัดไม้!"
```

1. **เมื่อ `乙` เดินหน้าเข้าหา `庚` (乙 $\rightarrow$ 庚):**
   * ไม้อ่อนยอมเลื้อยเกาะเกี่ยวเข้าหาแท่งโลหะ
   * **ผลลัพธ์:** เกิดการ **合 “ฮะ” (ภาคี) และแปรธาตุกลายเป็น “ธาตุทอง 庚”** สมบูรณ์แบบ
2. **เมื่อ `庚` จรเข้าฟาดฟัน `乙` (庚 $\rightarrow$ 乙):**
   * โลหะหนักฟาดฟันลงมาบนไม้เลื้อย
   * **ผลลัพธ์:** **不合 “ไม่ฮะ” และไม่แปรธาตุ! กลายเป็นปฏิกิริยา “ทองตัดไม้ / โลหะพิฆาตไม้” ทันที!**

## 4. ตรรกะสำหรับการเขียนโปรแกรมคำนวณ (`bazi.js`)

```javascript
// กฎการภาคีอสมมาตร 乙 และ 庚 ใน bazi.js
function evaluateYiGengCombination(stemA, stemB, isIncomingA) {
  // stemA = ตัวในดวงเดิม, stemB = ตัวที่จรมา
  if (stemA === '庚' && stemB === '乙') {
    // 乙 จรเข้ามาหา 庚 (乙 -> 庚)
    return {
      isCombined: true,
      transformedElement: 'Metal',
      nature: '乙 ยอมจำนนเกาะเกี่ยว 庚 แปรธาตุเป็นทองสำเร็จ'
    };
  } else if (stemA === '乙' && stemB === '庚') {
    // 庚 จรเข้ามาหา 乙 (庚 -> 乙)
    return {
      isCombined: false, // ไม่แปรธาตุ
      clashType: 'METAL_CHOPS_WOOD',
      nature: 'ทองตัดไม้ (庚 ฟัน 乙) ไม่เกิดการภาคีแปรธาตุ'
    };
  }
  return null;
}
```
