# คลังความรู้และกรณีศึกษาดวงจีนปาจื่อ (BaZi Knowledge Base & Case Studies)

รวบรวมหลักทฤษฎี กฎเกณฑ์การให้คะแนนกำลังดวง และกรณีศึกษาดวงจีนปาจื่อ (八字命理) เพื่อใช้เป็นฐานความรู้และพัฒนาระบบ AI พยากรณ์ของแม่หมอติ๊ดติ๊ด

| **Theory 06** | **六亲 “หลักชิง” (วงศ์ญาติ) & การสอบทานเวลาเกิด** | ตารางเทียบสิบเทพ vs วงศ์ญาติแยกชาย-หญิง, การอ่านราศีแฝง (暗藏), เทคนิคสอบทานเวลาเกิด (Birth Time Rectification), การกระทบของปีจรต่อบุคคล | [อ่านทฤษฎีที่ 06](theory/06_liu_qin_kinship_and_time_rectification.md) |
| **Theory 07** | **三會 “ซาหวย” (กระแสแห่งฤดูกาล) & ลำดับการร่วมธาตุ** | 4 กลุ่มทิศ/ฤดู (寅卯辰, 巳午未, 申酉戌, 亥子丑), สภาวะ 3 ระยะ (๔ อาชา, ๔ ขุนพล, ๔ ขุมคลัง), ลำดับความสำคัญสูงสุดของซาหวยเหนือ ซาฮะ/ปั๊วซาฮะ/หลักฮะ และกฎไม่ถูกขัดขวางโดย ชง/เฮ้ง/ผั่ว/ไห่ | [อ่านทฤษฎีที่ 07](theory/07_san_hui_seasonal_combinations.md) |
| **Theory 08** | **桃花 “ถ่อฮวย” (ดอกท้อ/ดาวเสน่ห์) — 子 卯 午 酉** | ปฏิกิริยา 90 องศาของ 4 แม่ธาตุ, กฎข้ามธาตุดินเร่งสปีด (午 -> 酉), การอ่านถ่อฮวยในดวง (ซ้ายไปขวา) vs วัยจร/ปีจร (ขวามาซ้าย), การวิเคราะห์ให้คุณ vs ให้โทษผ่านสิบเทพ | [อ่านทฤษฎีที่ 08](theory/08_tao_hua_peach_blossom.md) |
| **Theory 09** | **驛馬 “เอี้ยะแบ้” (ดาวม้าอาชา / การถ่ายเทธาตุและการเปลี่ยนแปลง)** | ความหมายลึกซึ้ง (ถ่ายเทธาตุ, โยกย้าย, จุดเปลี่ยนชีวิต), 4 กลุ่มซาฮะสู่ 4 อาชา (申子辰->寅, 亥卯未->巳, 寅午戌->申, 巳酉丑->亥), การเจอเพียงตัวเดียวในกลุ่มก็เกิดเอี้ยะแบ้, การวิเคราะห์ผลผ่านสิบเทพและวงศ์ญาติ | [อ่านทฤษฎีที่ 09](theory/09_yi_ma_travelling_horse.md) |
| **Theory 10** | **ธรรมชาติฟิสิกส์แห่งธาตุ — ดินกลบน้ำ vs น้ำเข้าบ่อ** | ปรัชญากฎตายตัวคนเป็น, 4 ดินตามสภาพจริง (辰ดินแห้ง, 未ดินร้อนผาก, 戌ดินชื้น, 丑ดินแฉะ), ดินจรเข้ามากลบน้ำ (辰 ไม่เกิดซาฮะ แต่ทำลายน้ำ) vs น้ำจรเข้าบ่อ (子 ท่วม 辰 เกิดซาฮะน้ำสมบูรณ์), การตีความผ่านสิบเทพ | [อ่านทฤษฎีที่ 10](theory/10_natural_physics_earth_water_interaction.md) |
| **Theory 11** | **財庫 “ไฉ่โข่ว” (๔ บุคลิกคลังสมบัติ) & “กุญแจไขคลัง”** | 4 อัตลักษณ์เศรษฐี (丑เศรษฐีผู้สูงศักดิ์ไม่โอ้อวด, 辰เศรษฐีเชื้อเจ้าบารมีสูง, 未เศรษฐีธรรมดารวยเงียบ, 戌เจ้าสัวการค้า), ตารางจับคู่คลังสมบัติกับกุญแจไขคลัง (辰-戌, 丑-未), กรณีศึกษาดวงลูกชายเจ้าสัวซีพี (มีทั้งคลัง 丑 และกุญแจ 未 ในดวง) | [อ่านทฤษฎีที่ 11](theory/11_cai_ku_vault_and_key.md) |
