# คลังความรู้และกรณีศึกษาดวงจีนปาจื่อ (BaZi Knowledge Base & Case Studies)

รวบรวมหลักทฤษฎี กฎเกณฑ์การให้คะแนนกำลังดวง และกรณีศึกษาดวงจีนปาจื่อ (八字命理) เพื่อใช้เป็นฐานความรู้และพัฒนาระบบ AI พยากรณ์ของแม่หมอติ๊ดติ๊ด

---

## 📚 หมวดทฤษฎีและกฎการคำนวณ (Core Theory & Scoring Rules)

| รหัส | หัวข้อทฤษฎี | ประเด็นสำคัญ / กฎเกณฑ์ | ลิงก์เอกสาร |
| :--- | :--- | :--- | :--- |
| **Theory 01** | **กำลังดิถี vs กำลังดวง** | การแยกแยะกำลังดิถีกับกำลังดวง, ข้อห้ามนำฮะ (三合, 六合, 五合) มานับกำลังดวง, สภาวะดวงอ่อนแต่ดิถีแข็ง | [อ่านทฤษฎีที่ 01](theory/01_day_master_vs_chart_strength.md) |
| **Theory 02** | **สูตรนับคะแนนกำลังดวงดิถีไม้ (甲/乙)** | น้ำหนัก 12 ราศีล่าง, กฎพิเศษดินเปียก 丑/辰 ได้ 0.5 คะแนนเฉพาะเสาเดือนและเวลา, กฎปัดเศษ .5 | [อ่านทฤษฎีที่ 02](theory/02_wood_daymaster_strength_scoring.md) |
| **Theory 03** | **ฤดูทั้ง ๔ และกำลังธาตุทั้ง ๕ ในแต่ละเดือน** | ตารางกำลัง 5 ธาตุใน 4 ฤดู (เข้มแข็ง/แข็งแรง/อ่อนแอ/เสื่อมโทรม/เสื่อมหมด), ดิถีเข้มแข็งตามฤดูแต่ดวงอ่อน, ดิถีอ่อนตามฤดูแต่ดวงแข็ง (อ่อนจนแข็ง) | [อ่านทฤษฎีที่ 03](theory/03_four_seasons_and_element_strength.md) |
| **Theory 04** | **หลักการอ่านโป๊ยหยี่สี่เถียว & เกณฑ์คะแนน 1-8 จุด** | ทิศทางการอ่านดวง (บนลงล่าง, ขวามาซ้าย), กฎจรบนชนบน/ล่างชนล่าง, กฎไม่ฟิกซ์ความหมายเสาตายตัว, เกณฑ์จำแนกดวง 1-8 จุด (สละดิถี, หยางในหยิน, หยิน, หยาง, หยินในหยาง) | [อ่านทฤษฎีที่ 04](theory/04_reading_mechanics_and_strength_scale.md) |
